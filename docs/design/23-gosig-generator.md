# 23. Go sig generator (`.gosig`)

**Status:** Wired into `goop check` for bare `import go "…"`. Explicit
`{ val … }` blocks remain authoritative (stubs not merged).

## Motivation

Goop reaches Go's stdlib through `import go "…" { val … }`, but every binding is
hand-written. H5 builds a `go/types`-driven generator that emits `.gosig` stubs
for a curated package set so the Go stdlib can act as Goop's library surface
without ceremony.

See `GOOP_UPDATES.md` §H5 / §H6.

## Architecture

```
goop gen-sig <pkg>
        │
        ▼
┌───────────────────┐     go/packages      ┌──────────────┐
│  gosiggen.Generate │ ───────────────────▶│ go/types pkg │
└─────────┬─────────┘                      └──────┬───────┘
          │                                       │
          │  MapType / emit                       │ exported
          ▼                                       │ objs
┌───────────────────┐                             │
│  .gosig text      │◀────────────────────────────┘
└─────────┬─────────┘
          │
          ▼
 $GOOP_HOME/build/go-sigs/<safe_pkg>.gosig
          │
          │  resolve (future compile load)
          ▼
 <project>/goop-sigs/<safe_pkg>.gosig   ← override wins
```

| Piece | Path | Role |
|-------|------|------|
| Generator | `src/internal/gosiggen/` | Load package, map types, emit `.gosig` |
| Existing lookup | `src/internal/gosig/` | Runtime `LookupFunc`/`LookupType` for typecheck FFI (unchanged) |
| CLI | `src/cmd/goop/gensig.go` | `goop gen-sig` |
| Cache | `$GOOP_HOME/build/go-sigs/` | Generated artifacts (not committed) |
| Override | `<project>/goop-sigs/` | Hand-curated wins over cache |

`GOOP_HOME` defaults to `~/.cache/goop` (same as compile/build cache).

## `.gosig` format

A `.gosig` file is the body of an `import go "path" { … }` block: opaque
`type` lines and `val` / method / field signatures.

```goop
(* Generated by goop gen-sig — DO NOT EDIT.
 * Package: strings (strings)
 * …
 *)

(* Types *)
type Builder
type Reader

(* Vals (funcs, methods, consts, vars) *)
val ToUpper : string -> string
val HasPrefix : string -> string -> bool
val (b : Builder ptr).WriteString : string -> int * error  (* (T, error): typecheck coerces to result *)
```

Filename sanitization: `/` and `.` → `_`
(`encoding/json` → `encoding_json.gosig`).

## Type mapping (foundation)

| Go | Goop `.gosig` | Notes |
|----|---------------|-------|
| `int`/`uint*`/`byte` | `int` | Matches existing typecheck FFI |
| `float32`/`float64` | `float` | |
| `bool` / `string` / `rune` | same | |
| `[]byte` | `bytes` | |
| `error` | `error` | |
| `any` / `interface{}` | `obj` | H5 spelling; language currently also has `any` |
| `*T` | `T ptr` | |
| `[]T` | `T go_slice` | Best-effort |
| `chan T` | `T chan` | Best-effort |
| `map[K]V` | *skipped* | Comment in file; defer map design |
| `(T, error)` | `T * error` | Product in `.gosig`; typecheck+codegen coerce to `('ok, error) result` (H6). `import go raw` keeps the tuple. |
| other multi-results | *skipped* | e.g. `(int, bool)` |
| variadic `...T` | `...obj` / `...T` | |
| named type in package | short name | plus `type Name` decl |
| methods | `val (x : Recv).M : τ` | pointer recv → `T ptr` |

### H6 — `(T, error)` → `result` (check/codegen)

`.gosig` files still emit the product `T * error` so hand-written and generated
sigs share one spelling. The type checker rewrites the binding to
`('ok, error) result`, and codegen wraps the Go call into `Ok` / `Error`.
Opt out with `import go raw "path" { … }`.

### `obj` vs `any`

H5 specifies `obj` for Go `any`. Today's Goop prelude exposes `any`. The
generator emits `obj` as specified; until `obj` is a first-class alias (or
sig loading rewrites), hand overrides may use `any` for live `import go`
blocks. Track as a follow-up when wiring auto-load into typecheck.


## Curated packages (H5)

`strings`, `fmt`, `errors`, `strconv`, `bytes`, `io`, `os`, `time`, `context`,
`sync`, `sync/atomic`, `sort`, `math`, `math/rand`, `net`, `net/http`,
`database/sql`, `encoding/json`, `encoding/csv`, `encoding/base64`,
`crypto/sha256`, `log/slog`.

Smoke subset for CI-ish checks: `strings`, `fmt`, `errors`, `strconv`.

## What is intentionally unfinished

1. **Full curated polish** — many packages emit useful stubs but skip
   unrepresentable exports; quality varies (`net/http`, `database/sql`).
2. **Cross-package named types** — e.g. `io.Writer`, `iter.Seq`,
   `unicode.SpecialCase` appear as qualified names without local `type`
   decls; full curated polish should either emit opaque deps or skip.
3. **Complex / anonymous interfaces / unsafe** — still skipped with reasons
   when not representable.

**Shipped (1.10):** compile-time auto-load of `.gosig` for bare `import go`;
Go `map[K]V` → `map[K] V` in gosiggen; `obj` ≡ `any`; H6 `(T, error)` →
`result` coercion (`import go raw` opt-out).
